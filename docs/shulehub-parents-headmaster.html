ShuleHub Parents menu

Headmaster guide · How to run guardians and student links

Sign in as Headmaster → left menu → Parents

Add parent · Link student · Message · Keep login safe

Who this is for

This page is the guardian directory. As Headmaster you can add parents, link them to students, send a message, and help them sign in. School admin and Academic master can do the same.

A parent login is not useful until they are linked to a student. You can also create a parent during Students → Admit student → Create parent now. Use this Parents page when the guardian already exists, or when you need to link, message, or fix a login.

Open the page

1 Sign in with your Headmaster email or phone.
2 If you have more than one school, pick the school first (Schools → Open school).
3 Click Parents in the left menu. Title: “Parents”. Subtitle: “Guardians and links”.

Add a parent

1 Click the gold Add parent button. The form opens over the page. The parent list is not shown.
2 Enter Name and Email.
3 Enter a phone number (Tanzania format). If you leave password blank, ShuleHub creates a temporary password and tries to SMS it to that phone.
4 Optional: occupation and address.
5 Click Save parent and confirm. The form closes. They appear in the list and on Users with role Parent.
Save stays disabled until there is a phone, or a password that meets the strength bar. Close, Cancel, Escape, or a click outside closes the form without saving. Email cannot be changed after save. Adding a parent does not link a student — do that next, or use Create parent now on Admit student.

Edit a parent

  1. Click the pen icon on the row. The same form opens. The parent list is hidden.
  2. Linked student names show under the title, or “No students linked”.
  3. Change name, phone, occupation, or address. Click Save changes and confirm.

Email stays locked. Cancel or Close returns you to the list.

Link a parent to a student

Use this when the parent already exists and the student has no parent yet.

1 Either click Link student at the top, or on a row click Link / Add student.
2 Choose the student (only students with no parent appear), the parent, and the relationship: Father, Mother, Guardian, or Other.
3 Click Link and confirm.

To remove a link, click Unlink on that student under the parent and confirm. The parent account is not deleted. The student can then be linked again.

If the student list says “Every live student already has a parent,” link from the Students page instead, or unlink first. A new guardian at admission is faster with Students → Admit student → Create parent now.

Message a parent

  1. Click the message icon on the row.
  2. Messages opens on their linked student’s thread.
  3. Click Write comment, type the note, optionally tick SMS, then Post comment.

If they have no student linked, you will see “Link a student first.” SMS is only an alert that a comment exists — they read and reply in the app.

Keep a parent login safe

Unlock

Shows when the row has a Locked chip (five failed logins). Confirm Unlock so they can sign in again at once.

Reset password

Creates a temporary password. If they have a phone, ShuleHub sends it by SMS. Confirm before you click.

Reset 2FA

Shows only if they enrolled Google Authenticator. After reset they set up 2FA again at next sign-in.

Deactivate

Archives the parent. They leave the normal list. Data stays. Confirm says Deactivate, not Delete.

Tick Show archived to find them. Click Restore. They return to the live list at once — you do not refresh. You can also Unlock, Reset password, and Reset 2FA on the Users page.
