ShuleHub Grades menu

Headmaster guide · How to enter exam marks, freeze them, and read term results

Sign in as Headmaster → left menu → Grades

Exam grid · Save · Excel import · Freeze at Verify · Term results

Who this is for

Headmaster, Academic master, and Teacher can open Grades and enter marks while the exam is unlocked. School admin, students, and parents do not see this menu. Students and parents see published results on report cards and their home, not this grid.

Grades is the mark book. Exams is where you create the sitting, send marks for checking, verify, reject, approve, and publish. You cannot create an exam here. You cannot verify an exam here.

Each exam paper (subject) has its own grid. Form 1 Midterm Maths is not the same grid as Form 1 Midterm English.

Open the page and pick a paper

1 Sign in. Open the correct school if you can switch schools.
2 Click Grades. The heading is Grades. The subtitle is “Exam marks”.
3 Choose an Exam. The list shows name, class, and status (DRAFT, ENTERED, VERIFIED…).
4 Choose a Subject. The subject must be a paper on that exam. If you pick a subject that is not on the exam, the grid fails.

Until both boxes are set, the card says “Pick an exam and subject.” The grid lists active students in that exam’s class, not one section.

The marks grid

Above the table: subject average, max marks, and pass marks from the paper. Search filters the rows by student name, admission number, or letter.

ColumnWhat you see
AdmAdmission number.
StudentName.
MarksWhile unlocked: a number box. While frozen: a bold label (or — if empty). No box to click.
GradeLetter from this school’s grading bands, from the percentage of max marks.
PosClass position among students who have a mark. Empty rows have no position.
TrashShown only when that student has a saved mark and the exam is not frozen. Confirms before delete.

Typing in a box does not save yet. Position and average update after Save grid or a successful import.

Save, delete, and search

1 Type marks. A mark must be from 0 up to that paper’s max (usually 100).
2 Click Save grid and confirm. Only rows with a number are sent. Empty boxes stay empty.
3 To remove one student’s marks, use trash on that row. Confirm “Delete marks for …?”.

Save needs at least one number. The success line is “Marks saved. Positions and averages updated.”

Leave a cell blank if that student has not sat yet. Do not type 0 unless they scored zero.

Excel template and import

Use this when you already have marks in a spreadsheet. Download the template from this same exam and subject so admission numbers match the class.

1 Pick exam and subject.
2 Click Download Excel template. Columns are Admission number, Student name, Marks.
3 Fill the Marks column. Keep admission numbers as they are.
4 Click Import Excel, choose the .xlsx file, and confirm. Marks in the file replace saved marks for those students. Blank mark cells are left unchanged.

Import is refused while frozen, if the file is not Excel, if the sheet is empty, or if the header is not Admission number and Marks. A row whose admission number is not in this class is reported as a problem.

When marks freeze

Marks freeze the moment Headmaster or Academic master clicks Verify on Exams. They stay frozen through Approve and Publish. They do not freeze at Send for checking.

Exam statusOn this page
DRAFTNumber boxes. Save, import, and trash work.
ENTEREDStill boxes. You can still correct marks before Verify.
VERIFIED, APPROVED, PUBLISHEDGold note: “Marks are frozen after verification.” Each mark is a label, not a box. Trash is hidden. Import and Save grid are grey. The server also refuses those actions.
REJECTEDBoxes come back. Fix marks, save, then Send for checking again on Exams.

To unlock: Exams → Reject (Headmaster or Academic master). Then reload Grades. Unpublish hides results from families but does not unlock the grid.

Download Excel template still works while frozen, so you can keep a copy. Import does not.

Term results

The gold Term Results button (top right) is not the exam grid. It opens a form, then a second table of combined scores for a class and subject.

1 Click Term Results.
2 Year defaults to the current year. Term can stay Whole year, or pick one term.
3 Pick class and subject. Click Term Results in the form.

Default math (change weights on Academics → Results):

  • Semi-terminal result = midterm × 10% + semi exam × 90%.
  • Term result = that semi-terminal result × 50% + terminal exam × 50%.

An exam not yet taken is left out of that student’s mix. The table columns are Midterm, Semi exam, Semi result, Terminal exam, Term result, Grade. Search works on this table too. This view is read-only. You do not type marks here.

Assignments are not in this math. Official term results come from exam components only.

Letters and pass marks

The letter on the grid is this school’s grading bands (Academics → Grading), from the student’s mark as a percentage of the paper max. Pass / fail on the paper uses the paper’s pass mark (set when you added the paper on Exams). Those two ideas can differ: a school can give a D that still “passes” the paper, or the other way around, depending on bands and pass mark.

Icons and confirms

  • Trash = delete one student’s marks (unlocked exams only).
  • Save grid, Import Excel, and delete ask you to confirm.
  • Frozen marks are labels, not disabled boxes. That is deliberate so the page does not look editable.
