ShuleHub Academics menu

Headmaster guide · How to set up the school year, classes, rooms, teachers, and grading

Sign in as Headmaster → left menu → Academics

Years · Terms · Classes · Subjects · Rooms · Allocations · Result weights · Grading bands

Who this is for

Academics is the school’s structure. Students, exams, the timetable, attendance, and report cards all hang off what you set here. Headmaster, School admin, and Academic master can open the page. Some buttons are limited — see Who can do what.

Academics is not the teacher staff list, the student list, the exam mark book, or the weekly timetable. Those are separate menus. This page only builds the skeleton those menus use.

Set up in this order

1 Confirm terms-per-year with platform admin (2 or 4). This is per organization, on Configurations.
2 Add the academic year. Terms are created automatically.
3 Adjust term dates if the split is wrong.
4 Add classes for that year (Form 1, Form 2…).
5 Add sections (A, B) so students can be admitted.
6 Add subjects (Mathematics, English…).
7 Add teachers on the Teachers menu (staff directory), then come back here.
8 Allocate who teaches what (Academics → Teachers tab).
9 Add buildings, then rooms, if you will use the timetable.
10 Save grading bands for this school. Optionally save result weights for the year.
You can admit students after you have a year, a class, and a section. You can create exams after you have a year, class, and subjects. You can build a timetable after allocations and rooms exist.

Years & terms

Academic years

A year is the container for classes, exams, fees, allocations, and enrolments. Exactly one year should be Current. Admit, exams, and promotion use the current year by default.

1 Tab Years & terms. Click Add year.
2 Enter a name (2026/2027), start date, and end date. End must be after start.
3 Save and confirm. Terms appear automatically: Term 1 … Term N, dates split evenly across the year.

N is 2 or 4, from the organization’s setting on platform Configurations. Changing that setting later does not rewrite years you already created. It only affects new years.

If the new year is saved as current (the usual case), Term 1 is marked Current. Other years lose the Current chip.

  • Make current — shown on years that are not current. Confirm first. Only one current year at a time.
  • Pen — change name or dates. Does not recreate terms.
  • Trash — delete the year only after you have cleared what hangs on it (see failures table).
  • Click the year row to select it. The Terms card then shows that year’s terms.

Terms

Terms belong to the selected year. You normally only edit dates, or add an extra term if you must.

  • Add term — year (defaults to the selected year), name, start, end. End must be after start. Name cannot repeat in that year.
  • Pen — rename or move dates.
  • Trash — refused if exams or result weights still use the term.
  • Current marks the active term for that year.

Classes and sections

A class is “Form 3 in 2026/2027”. A section is “Form 3 A”. Students sit in a section. You can have a class with no section, but admit and the timetable work better once A or B exists.

Add a class

1 Tab Classes. Click Add class.
2 Pick the year (defaults to the current year). Enter name (Form 3) and code (F3).
3 Save and confirm. The code cannot repeat in that same year.

There is no edit-class form on this screen. To correct a class, delete it (if it is unused) and add it again, or leave it and add a new one.

Add a section

1 On the class row, click Add section.
2 Class is already chosen. Enter name (A) and optional capacity (seats).
3 Save. The same section name cannot repeat in that class.
  • Trash on the class — refused if students, remaining sections, exams, or fee structures still use it. Allocations and notices for that class are cleared automatically.
  • Trash on the section — refused if students are still in it. Allocations, timetable slots, and attendance rows for that section are cleared.

Subjects and curriculum topics

Subjects

Subjects are school-wide. You do not recreate Mathematics every year. They appear on allocations, the timetable, exams, and grades.

1 Tab Subjects. Click Add subject.
2 Enter name (Mathematics) and code (MATH). Code must be unique at this school.
3 Save. Use the pen later to rename. Trash is refused if exam papers or grades still use the subject. Allocations and timetable slots for it are removed with the subject.

Curriculum topics

Optional syllabus headings (Quadratic equations) under a subject. You can limit a topic to one class, or leave class as Any class. Objectives show on the card.

1 On the same tab, click Add topic.
2 Pick subject, optional class, title, and optional objectives.
3 Save. Pen to edit. Trash to delete. Topics do not block deleting a subject on their own.

Curriculum topics are for planning. Official term results and report cards use exams and grading bands, not topics.

Rooms (buildings and classrooms)

Buildings

A building is a name in a dropdown (Block A, Science block). Headmaster and School admin create them. Academic master can see the list and pick a building when adding a room, but cannot add the building.

  • Add building — name (required), notes (optional). Name must be unique at the school.
  • Pen — rename. Rooms that pointed at the old name follow the new name.
  • Trash — refused until every room in that building is removed.

Classrooms (rooms)

A room is what the timetable uses (Lab 1, Hall).

1 Click Add room.
2 Enter name. Optional: code, capacity, building (from the list above), notes.
3 Save. Name and code (if you set one) must be unique at the school.

Pen to edit. Trash is refused if the room is still on the timetable.

Teachers tab (who teaches what)

This tab is not the staff directory. Add people on the Teachers menu first. Here you only say who teaches which subject to which class this year.
1 Tab Teachers. Click Allocate teacher.
2 Pick teacher, subject, class, year (defaults to current). Section is optional — leave “Whole class” if they teach every stream.
3 Save. The same teacher + subject + class + section + year cannot be saved twice.

Pen to change the link. Trash removes only the allocation, not the teacher account. You need allocations before you build a useful timetable.

Results (how marks combine)

Official term results come from exams, not from assignments. Assignments are continuous assessment only. This tab sets the weights ShuleHub uses when it combines exam components.

Default math (Appendix A):

  • Semi-terminal result = midterm × 10% + semi exam × 90%.
  • Term result = that semi-terminal result × 50% + terminal exam × 50%.

Those two pairs must each add to 100. You can save a rule for:

  • The whole year (term = All terms, subject = All subjects), or
  • One term, or
  • One subject, or
  • One term and one subject.

The most specific saved rule wins. If nothing is saved, the 10/90 then 50/50 default is used.

Headmaster and Academic master can save. School admin should not use this tab to write weights.

Saved rules appear as a short list under the form (subject name or “All subjects”, then the four numbers).

Grading (letters and mark ranges)

Grading bands belong to this school only. They are not shared across the organization. Report cards and grades look up the letter from the student’s percentage using this list.

Until this school saves its own bands, ShuleHub shows a default A–F set:

1 Tab Grading. If the defaults are what you want, click Save for this school and confirm.
2 Or click Add band. Enter letter, points, from %, to %. Confirm. Bands sort high-to-low by from %.
3 Pen to change a band. Trash to remove one. Search filters by letter, range, or points.

Headmaster and Academic master can add, edit, delete, and save. School admin can see the list.

A percentage is matched to the first band where it falls between from % and to %. Leave no gaps if you do not want a leftover F from the built-in fallback.

What other menus use this

Students

Admit into a class and section of a year. Promote into the next year’s class. A student can also have no class.

Exams and Grades

An exam belongs to a year (and usually a term and class). Papers pick subjects. Official term results combine exam components using Results weights, then letters from Grading.

Timetable

Needs allocations (who teaches what) and rooms. Buildings are only the dropdown behind rooms.

Teachers (directory)

People records. Department list is separate. Qualification list is set by platform admin on Configurations. Allocations on Academics point at these people.

Fees

Fee structures can be tied to a year and class. You cannot delete a year or class that still has fees.

Report cards

Show exam and term results. Letters and points come from this school’s grading bands.

Icons and confirms (whole page)

  • Pen = edit. Trash = delete. Plus = add.
  • Save, delete, make current, and save weights / bands ask for confirm.

  • Empty states tell you the next step (add a year first, add a building first, and so on).
