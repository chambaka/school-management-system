What each role can do

Platform

SUPER_ADMIN

  • Create and manage tenants and schools
  • Platform config and platform audit
  • Switch into a school
  • In single-tenant mode, uses Headmaster school screens for the default organization
  • Does not do day-to-day school work unless a school is selected
School lead

HEADMASTER

  • Schools in the organization (add / switch)
  • Students, parents, teachers, officers — create and manage
  • Academics (classes, subjects) — manage
  • Timetable — view only
  • Attendance — view; manage teacher attendance
  • Exams — approve / publish; grades and report cards — view / approve
  • Fees and invoices — view (cannot generate invoices or record payments)
  • Notices (school-wide), messages, SMS to parents, branding, school audit
Teaching operations

ACADEMIC_MASTER

  • Students, parents, teachers, officers — manage
  • Academics — manage
  • Timetable — the only role that can edit it
  • Attendance — view and enter
  • Exams — manage; grades — enter / verify; report cards — prepare
  • Fees — view only (no payments or invoice write)
  • Academic notices, messages to teachers, SMS to parents, limited audit
  • Cannot manage branding or organization schools
Finance

ACCOUNTANT

  • Student directory — limited (billing)
  • Fees, invoices, payments — create, generate, record
  • Financial reports / finance audit
  • Finance notices and finance-related messages
  • Cannot register students, manage teachers, edit timetable, or enter attendance / marks
Assigned work

TEACHER

  • Students — assigned classes
  • Timetable (view), attendance (enter), exams / grades (enter marks)
  • Assignments / assessments (class)
  • Report cards — view / prepare
  • Notices (class), messages to parents
  • Cannot register students, manage teachers, edit timetable, or see fees
Family / learner

PARENT and STUDENT

  • Parent: view own children — classes, subjects, timetable, attendance, exams, results, report cards
  • Parent: view fees and pay their account; receive notices; message the school
  • Parent: cannot manage staff, academics, or school finance
  • Student: own home, timetable, attendance, notices, own finance / report card
  • Student: cannot manage anything
